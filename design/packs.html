camayoc

Design: packs and one front door

Status: proposed (2026-11-28). Nothing on this page is built unless a "today" column says so.

Camayoc promises a memory that is checked on the way in. That holds on a store someone has prepared by hand, and it does not hold for a person starting fresh. The pieces that keep the promise are spread over one CLI, two MCP servers and about 115 scripts. This design makes Camayoc one product: a domain is declared once as a pack, and cy is the one way to check it, load it and use it.

The commands half of this, where an agent is handed exactly the commands its work item calls for, is designed in the Capability Layer Design of 2026-11-25 and tracked as epic aegis-ssx5. This page does not repeat it. It covers what that design stands on, and how both meet the Shuttle orchestrator.

The model

thingwhat it is
PackOne directory that declares a domain: its terms, shapes, stored queries, competency questions, memory entities and commands, with a manifest that names its version.
Installed packA fact in the store: which pack, which version, which digest, loaded when and by whom.
SurfaceWhat an agent touches: a cy subcommand, an MCP tool, a skill. Each is generated from a pack.
ReceiptThe record of one call: the command, the caller, the outcome and, for a refusal, the reason.
VerdictThe result of one competency question on one store: passes, fails or cannot tell.

A pack, start to finish

  1. Declare. An author writes or edits a pack. A pack is plain files in a repository, so a change is reviewed like code.
  2. Check. cy pack check runs without a store. It refuses a pack whose shapes do not parse, whose questions have no query, whose queries name terms the pack does not declare, or whose commands have no test.
  3. Load. cy pack load asks Quipu for a dry run, then loads the pack and writes the installed-pack fact. An additive change loads directly. A change that tightens or removes something goes to a person as a schema proposal.
  4. Generate. cy reads the installed packs and offers their commands as a CLI and as MCP tools, with the guidance text an agent reads.
  5. Use. Each call is checked against the pack's shapes and leaves a receipt, whether it was admitted or refused.
  6. Learn. Refused calls and calls to commands that do not exist reach Quipu through Desire Path, grouped by pattern. A repeated pattern becomes a proposal against one pack.

cy pack status compares a store with the packs it should hold and reports each difference: a missing query, an older shape, a pack that was never loaded. Chaski raises that as an alarm. The missing memory queries in requirement 2 are the kind of gap it reports.

One front door

cy becomes the way to do everything Camayoc does. Scripts stay as the implementation.

commanddoesreplaces
cy initFinds or starts a store, loads the core and memory packs, registers the planes, adds the first person and agent, and proves the gate.scripts/bootstrap.sh, scripts/planes.py ensure
cy entity add NAME --type PersonAdds a person, a system or an agent. It refuses a name that is close to one that exists and shows the match.no command today
cy pack check, load, statusThe pack steps above.memory_tools.py --check, memory_schema_proposal.py, the load steps in the bootstrap
cy admitOne way in for an event or a document: map it, tag it, validate it as a dry run, then write it or quarantine it with the reason. Sources plug in as adapters.ingest_cdevents.py, github_ingress.py, alertmanager_ingress.py and the other producers
cy ask "QUESTION"Maps the question to a stored query, runs it and answers with how each fact was learned. It says so when no query answers the question.scripts/competency.py, the map_question tool on its own
cy record, cy recallUnchanged.

Three rules of today's memory tool change with this work:

  • Replacing a record is one write. Today the new record and the mark on the old one are two writes, and a failure between them leaves two current records.
  • A preference's key includes its context, so a chat preference and an email preference on one topic do not replace each other.
  • cy installs from a tagged release, not from the head of main.

Questions are the tests

A pack does not load without its questions, and a question is a test.

  • An answer question has a stored query and a fixture, and its verdict is checked in CI.
  • A discovery question checks that an agent with a need finds the right command or query. Jev maps it and must reach the 0.75 floor.
  • A refusal question names something that must be refused.

A pack's release is blocked when a verdict gets worse. The 33 questions that could have a query get one, and Jev's score is measured again on all 124.

How this meets the Shuttle orchestrator

The orchestrator design gives each step a performer, inputs and an output contract. A pack supplies all three.

in a Shuttle stepcomes from a pack as
A code step's performerA command the pack declares, with its reach and its undo.
An output contract of kind shape or askA shape or a stored query the pack ships.
An agent step's task pendantThe grant resolved for the step: the pack's commands the agent may call.
A step's outputThe receipt of the call that produced it.
The workflow definitionA file in the same pack as the commands and agent types it uses.

A deployment then installs a workflow, its commands, its checks and its vocabulary as one reviewed bundle.

Decisions this needs

#decisionrecommendation
1Whether the pack is the unit and cy the only front doorYes. Everything Camayoc owns moves into packs, and every user-facing script becomes a cy subcommand. It extends the generator that already produces the memory commands.
2How a first person or system gets into a storecy init adds the first person and agent, and cy entity add adds more and refuses near-duplicates. The alternative, where cy record creates any name it does not know, would fill the store with misspelled duplicates.
3What loads without a personAn additive change loads after its dry run passes: a new query, a new optional property, a new class under a governed parent. A change that tightens or removes goes to a person. This follows the 2026-11-06 ruling that Camayoc should make adding shapes easier and not wait on one person.
4What goes firstPhase 0 now, as small items, because it repairs things that are broken today. Phases 1 to 3 queue behind the three milestones. Phase 4 keeps the rank epic aegis-ssx5 already has.

What stays the same

  • cy record and cy recall keep their flags and their refusals.
  • Every record still says whether it was observed, declared or inferred, and inferred never overrides declared.
  • The gate proof stays. cy init reports a store ready only after the store has refused a record that does not say how it was learned.
