# Usage generation contract

The [proposal 42 contract](usage-generations.contract.txt) is retained byte for
byte as the normative starting contract. The approved
[proposal 43 attribution amendment](usage-attribution-state.md) narrows its
conditional request shape; it does not load or activate a profile.

See [source behavior and remaining gates](usage-generations-source.md) for
the implementation boundaries, source-only evidence and rollback. Neither
a valid manifest nor source installation proves complete per-seed accounting.
