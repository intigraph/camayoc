# Completion proof markers

The base maps missing, explicitly false and malformed receipt proofs to the
same false bits. The candidate adds fixed categories and recognizes `queued`.
All four fixtures remain frozen, make one existing status call and make no
absence queries. This is an offline source demonstration with mocked responses.

Base: `79b1744792684b011806d24592caa895d284a2ee`. Run
`python3 docs/demos/completion-proof-markers/demo.py` from the repository root.
No installed service or live request is exercised. The old boolean fields
remain unchanged; no raw malformed value is retained.

[Recorded output](output.log) and [timing](timing.log) can be replayed with
`scriptreplay --log-out output.log --log-timing timing.log`.
